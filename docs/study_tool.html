Simulation loop

main() orchestrates a classic loop: handle events, compute dt, update circles, update effects, then draw the frame.

  • The app uses clock.tick(FPS) for elapsed time.
  • Paused time sets sim_dt to zero.
  • Speed controls scale simulation time without changing frame timing.

Behavior and stability

Circle behavior is shaped by size-based speed caps, flee/chase rules, overlap correction, soft wall repulsion, and hard boundary bounce logic.

  • apply_interactions() chooses a chase target.
  • find_safe_position() prevents overlapping respawns.
  • Effect handles death and rebirth visuals.
